# 0.1.12 验证边界

本版纠正开源仓库范围：音乐源码集中到src，必要模块按PCM/图片/AAC/USB分层，
第三方库集中到third_party。USB/固件/H1NET改为引用公开SDK63fa3c8；
不再复制新闻、Bilibili、浏览器、配网或H1Debug项目目录。

测试支持已从原先跨项目继承改为独立的固件服务模型、纯内存邮箱和合成HTTP/AAC对端。
删除硬件调试CLI、其他应用测试入口、旧失败重试选项和废弃图标草稿。

## 本次执行入口

- `python tools/check_repository.py`：禁止兄弟应用目录/硬件调试CLI和跨项目测试导入再次进入仓库。
- `python tools/build_h1_qqmusic.py --all`：正式/模型BDA构建、标题/分类/资源/入口和格式检查。
- `python tests/test_modes.py`：1..12首策略、真实AAC EOF自动切歌、后台视图、循环/随机历史、触控、配置保存恢复、权限跳过和短片尾/定位。
- `python tests/test_buffer.py`：真实PCM储备、BUSY、三次合法脚本游标欠载后的进度恢复、错误保留与清理。
- `python tests/test_navigation.py`：后台列表/首页/分页/搜索、当前会话保持、扫码/权限、原生输入、拖动。
- `python tests/test_stream.py`：实际C线协议、700ms模拟CDN下的预取、任务上限、跳转/BUSY/释放。

MIPS测试执行实际链接的应用、MOV和C运行时；固件/DAC输入为明确模型，AAC由PC PyAV真实解码。
不是完整BBK固件模拟器，也不是ESP芯片/物理无线吞吐验证；不直接拿模型时间声称真机提速。
本次具体构建/测试报告由对应CI提供；精确BDA哈希见Release的SHA256SUMS及构建信息。

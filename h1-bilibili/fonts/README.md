# H1Bili16 pixel font

Client-local GB2312 + printable ASCII subset of GNU Unifont 16.0.04, by Roman
Czyborra, Paul Hardy and the Unifont contributors. Glyph shapes are copied
losslessly from the upstream HEX file: no scaling, thresholding or smoothing.
ASCII uses 8×16 cells; full-width glyphs use 16×16 cells.

This subset is named **H1Bili16**. It is distributed under the SIL Open Font
License 1.1, included here in `OFL-1.1.txt`. Upstream's dual-license notice is
preserved in `LICENSE-upstream.txt`. Origin URLs and SHA256 hashes are in
`sources.json`; `generated.json` records the generated table's identity.

Rebuild with `python tools/generate_h1_bili_font.py`. The original compressed
HEX source is included for reproducibility. The Bilibili and QQ Music clients
use this font; shared browser and game font tables are unchanged.
